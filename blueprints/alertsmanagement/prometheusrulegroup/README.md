# Krateo Blueprint — Azure Alertsmanagement PrometheusRuleGroup

> Generated by `tools/asogen` from the Azure Service Operator `PrometheusRuleGroup` CRD (`alertsmanagement.azure.com`).

Provisions an Azure Alertsmanagement **PrometheusRuleGroup** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `alertsmanagement.azure.com/v1api20230301` `PrometheusRuleGroup` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureAlertsmanagementPrometheusrulegroup` Composition you create
becomes an Azure PrometheusRuleGroup.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20230301`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO PrometheusRuleGroup spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-alertsmanagement-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureAlertsmanagementPrometheusrulegroup type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureAlertsmanagementPrometheusrulegroup` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurealertsmanagementprometheusrulegroups`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-alertsmanagement-prometheusrulegroup`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureAlertsmanagementPrometheusrulegroup
metadata:
  name: my-prometheusrulegroup
  namespace: azure-alertsmanagement-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... PrometheusRuleGroup spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurealertsmanagementprometheusrulegroups.composition.krateo.io -n azure-alertsmanagement-system
kubectl get prometheusrulegroups.alertsmanagement.azure.com -A
```
