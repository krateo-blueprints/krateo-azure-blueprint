# Krateo Blueprint — Azure Cognitiveservices Deployment

> Generated by `tools/asogen` from the Azure Service Operator `Deployment` CRD (`cognitiveservices.azure.com`).

Provisions an Azure Cognitiveservices **Deployment** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `cognitiveservices.azure.com/v1api20250601` `Deployment` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureCognitiveservicesDeployment` Composition you create
becomes an Azure Deployment.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20250601`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Deployment spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-cognitiveservices-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureCognitiveservicesDeployment type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureCognitiveservicesDeployment` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurecognitiveservicesdeployments`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-cognitiveservices-deployment`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureCognitiveservicesDeployment
metadata:
  name: my-deployment
  namespace: azure-cognitiveservices-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Deployment spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurecognitiveservicesdeployments.composition.krateo.io -n azure-cognitiveservices-system
kubectl get deployments.cognitiveservices.azure.com -A
```
