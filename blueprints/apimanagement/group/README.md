# Krateo Blueprint — Azure Apimanagement Group

> Generated by `tools/asogen` from the Azure Service Operator `Group` CRD (`apimanagement.azure.com`).

Provisions an Azure Apimanagement **Group** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `apimanagement.azure.com/v20240501` `Group` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureApimanagementGroup` Composition you create
becomes an Azure Group.

This CRD serves **2** versions upstream; this blueprint targets
`v20240501`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Group spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-apimanagement-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureApimanagementGroup type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureApimanagementGroup` Composition type (`composition.krateo.io/v0-1-0`,
plural `azureapimanagementgroups`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-apimanagement-group`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureApimanagementGroup
metadata:
  name: my-group
  namespace: azure-apimanagement-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Group spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azureapimanagementgroups.composition.krateo.io -n azure-apimanagement-system
kubectl get groups.apimanagement.azure.com -A
```
