# Krateo Blueprint — Azure Keyvault Vault

> Generated by `tools/asogen` from the Azure Service Operator `Vault` CRD (`keyvault.azure.com`).

Provisions an Azure Keyvault **Vault** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `keyvault.azure.com/v1api20230701` `Vault` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureKeyvaultVault` Composition you create
becomes an Azure Vault.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20230701`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Vault spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-keyvault-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureKeyvaultVault type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureKeyvaultVault` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurekeyvaultvaults`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-keyvault-vault`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureKeyvaultVault
metadata:
  name: my-vault
  namespace: azure-keyvault-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Vault spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurekeyvaultvaults.composition.krateo.io -n azure-keyvault-system
kubectl get vaults.keyvault.azure.com -A
```
