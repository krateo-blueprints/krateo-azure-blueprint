# Krateo Blueprint — Azure Documentdb MongodbDatabaseCollectionThroughputSetting

> Generated by `tools/asogen` from the Azure Service Operator `MongodbDatabaseCollectionThroughputSetting` CRD (`documentdb.azure.com`).

Provisions an Azure Documentdb **MongodbDatabaseCollectionThroughputSetting** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `documentdb.azure.com/v1api20240815` `MongodbDatabaseCollectionThroughputSetting` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureDocumentdbMongodbdatabasecollectionthroughputsetting` Composition you create
becomes an Azure MongodbDatabaseCollectionThroughputSetting.

This CRD serves **6** versions upstream; this blueprint targets
`v1api20240815`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO MongodbDatabaseCollectionThroughputSetting spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-azure-blueprint/releases
kubectl create namespace azure-documentdb-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-azure-blueprint/releases/download/${VERSION}/compositiondefinition-azure-documentdb-mongodbdatabasecollectionthroughputsetting.yaml"   # publishes the AzureDocumentdbMongodbdatabasecollectionthroughputsetting type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureDocumentdbMongodbdatabasecollectionthroughputsetting` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `azuredocumentdbmongodbdatabasecollectionthroughputsettings`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-documentdb-mongodbdatabasecollectionthroughputsetting` at that version.
