# Krateo Blueprint — Azure Apimanagement NamedValue

> Generated by `tools/asogen` from the Azure Service Operator `NamedValue` CRD (`apimanagement.azure.com`).

Provisions an Azure Apimanagement **NamedValue** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `apimanagement.azure.com/v1api20240501` `NamedValue` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureApimanagementNamedvalue` Composition you create
becomes an Azure NamedValue.

This CRD serves **12** versions upstream; this blueprint targets
`v1api20240501`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO NamedValue spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-apimanagement-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureApimanagementNamedvalue type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureApimanagementNamedvalue` Composition type (`composition.krateo.io/v0-1-0`,
plural `azureapimanagementnamedvalues`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-apimanagement-namedvalue`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureApimanagementNamedvalue
metadata:
  name: my-namedvalue
  namespace: azure-apimanagement-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... NamedValue spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azureapimanagementnamedvalues.composition.krateo.io -n azure-apimanagement-system
kubectl get namedvalues.apimanagement.azure.com -A
```
