# Krateo Blueprint — Azure Kusto Database

> Generated by `tools/asogen` from the Azure Service Operator `Database` CRD (`kusto.azure.com`).

Provisions an Azure Kusto **Database** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `kusto.azure.com/v1api20240413` `Database` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureKustoDatabase` Composition you create
becomes an Azure Database.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20240413`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Database spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-kusto-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureKustoDatabase type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureKustoDatabase` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurekustodatabases`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-kusto-database`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureKustoDatabase
metadata:
  name: my-database
  namespace: azure-kusto-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Database spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurekustodatabases.composition.krateo.io -n azure-kusto-system
kubectl get databases.kusto.azure.com -A
```
