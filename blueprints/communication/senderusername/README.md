# Krateo Blueprint — Azure Communication SenderUsername

> Generated by `tools/asogen` from the Azure Service Operator `SenderUsername` CRD (`communication.azure.com`).

Provisions an Azure Communication **SenderUsername** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `communication.azure.com/v20230401` `SenderUsername` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureCommunicationSenderusername` Composition you create
becomes an Azure SenderUsername.

This CRD serves **2** versions upstream; this blueprint targets
`v20230401`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO SenderUsername spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-communication-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureCommunicationSenderusername type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureCommunicationSenderusername` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurecommunicationsenderusernames`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-communication-senderusername`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureCommunicationSenderusername
metadata:
  name: my-senderusername
  namespace: azure-communication-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... SenderUsername spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurecommunicationsenderusernames.composition.krateo.io -n azure-communication-system
kubectl get senderusernames.communication.azure.com -A
```
