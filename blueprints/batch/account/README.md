# Krateo Blueprint — Azure Batch BatchAccount

> Generated by `tools/asogen` from the Azure Service Operator `BatchAccount` CRD (`batch.azure.com`).

Provisions an Azure Batch **BatchAccount** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `batch.azure.com/v1api20210101` `BatchAccount` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureBatchAccount` Composition you create
becomes an Azure BatchAccount.

This CRD serves **6** versions upstream; this blueprint targets
`v1api20210101`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO BatchAccount spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-batch-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureBatchAccount type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureBatchAccount` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurebatchaccounts`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-batch-account`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureBatchAccount
metadata:
  name: my-account
  namespace: azure-batch-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... BatchAccount spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurebatchaccounts.composition.krateo.io -n azure-batch-system
kubectl get batchaccounts.batch.azure.com -A
```
