# Krateo Blueprint — Azure Network TrafficManagerProfilesNestedEndpoint

> Generated by `tools/asogen` from the Azure Service Operator `TrafficManagerProfilesNestedEndpoint` CRD (`network.azure.com`).

Provisions an Azure Network **TrafficManagerProfilesNestedEndpoint** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `network.azure.com/v1api20220401` `TrafficManagerProfilesNestedEndpoint` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureNetworkTrafficmanagerprofilesnestedendpoint` Composition you create
becomes an Azure TrafficManagerProfilesNestedEndpoint.

This CRD serves **2** versions upstream; this blueprint targets
`v1api20220401`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO TrafficManagerProfilesNestedEndpoint spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-network-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureNetworkTrafficmanagerprofilesnestedendpoint type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureNetworkTrafficmanagerprofilesnestedendpoint` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurenetworktrafficmanagerprofilesnestedendpoints`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-network-trafficmanagerprofilesnestedendpoint`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureNetworkTrafficmanagerprofilesnestedendpoint
metadata:
  name: my-trafficmanagerprofilesnestedendpoint
  namespace: azure-network-system

  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace

    name: my-resource-group
```

### Check status

```sh
kubectl get azurenetworktrafficmanagerprofilesnestedendpoints.composition.krateo.io -n azure-network-system
```
