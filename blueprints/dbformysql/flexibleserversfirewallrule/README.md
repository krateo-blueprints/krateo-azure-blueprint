# Krateo Blueprint — Azure Dbformysql FlexibleServersFirewallRule

> Generated by `tools/asogen` from the Azure Service Operator `FlexibleServersFirewallRule` CRD (`dbformysql.azure.com`).

Provisions an Azure Dbformysql **FlexibleServersFirewallRule** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `dbformysql.azure.com/v1api20231230` `FlexibleServersFirewallRule` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureDbformysqlFlexibleserversfirewallrule` Composition you create
becomes an Azure FlexibleServersFirewallRule.

This CRD serves **16** versions upstream; this blueprint targets
`v1api20231230`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO FlexibleServersFirewallRule spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-dbformysql-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureDbformysqlFlexibleserversfirewallrule type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureDbformysqlFlexibleserversfirewallrule` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuredbformysqlflexibleserversfirewallrules`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-dbformysql-flexibleserversfirewallrule`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureDbformysqlFlexibleserversfirewallrule
metadata:
  name: my-flexibleserversfirewallrule
  namespace: azure-dbformysql-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... FlexibleServersFirewallRule spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuredbformysqlflexibleserversfirewallrules.composition.krateo.io -n azure-dbformysql-system
kubectl get flexibleserversfirewallrules.dbformysql.azure.com -A
```
