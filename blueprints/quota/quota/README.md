# Krateo Blueprint — Azure Quota Quota

> Generated by `tools/asogen` from the Azure Service Operator `Quota` CRD (`quota.azure.com`).

Provisions an Azure Quota **Quota** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `quota.azure.com/v1api20250901` `Quota` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureQuotaQuota` Composition you create
becomes an Azure Quota.

This CRD serves **2** versions upstream; this blueprint targets
`v1api20250901`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Quota spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-quota-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureQuotaQuota type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureQuotaQuota` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurequotaquotas`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-quota-quota`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureQuotaQuota
metadata:
  name: my-quota
  namespace: azure-quota-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Quota spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurequotaquotas.composition.krateo.io -n azure-quota-system
kubectl get quotas.quota.azure.com -A
```
