# Krateo Blueprint — Azure Servicebus NamespacesAuthorizationRule

> Generated by `tools/asogen` from the Azure Service Operator `NamespacesAuthorizationRule` CRD (`servicebus.azure.com`).

Provisions an Azure Servicebus **NamespacesAuthorizationRule** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `servicebus.azure.com/v1api20240101` `NamespacesAuthorizationRule` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureServicebusNamespacesauthorizationrule` Composition you create
becomes an Azure NamespacesAuthorizationRule.

This CRD serves **8** versions upstream; this blueprint targets
`v1api20240101`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO NamespacesAuthorizationRule spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-servicebus-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureServicebusNamespacesauthorizationrule type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureServicebusNamespacesauthorizationrule` Composition type (`composition.krateo.io/v0-1-0`,
plural `azureservicebusnamespacesauthorizationrules`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-servicebus-namespacesauthorizationrule`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureServicebusNamespacesauthorizationrule
metadata:
  name: my-namespacesauthorizationrule
  namespace: azure-servicebus-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... NamespacesAuthorizationRule spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azureservicebusnamespacesauthorizationrules.composition.krateo.io -n azure-servicebus-system
kubectl get namespacesauthorizationrules.servicebus.azure.com -A
```
