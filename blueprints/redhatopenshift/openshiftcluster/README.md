# Krateo Blueprint — Azure Redhatopenshift OpenShiftCluster

> Generated by `tools/asogen` from the Azure Service Operator `OpenShiftCluster` CRD (`redhatopenshift.azure.com`).

Provisions an Azure Redhatopenshift **OpenShiftCluster** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `redhatopenshift.azure.com/v1api20231122` `OpenShiftCluster` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureRedhatopenshiftOpenshiftcluster` Composition you create
becomes an Azure OpenShiftCluster.

This CRD serves **2** versions upstream; this blueprint targets
`v1api20231122`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO OpenShiftCluster spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-redhatopenshift-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureRedhatopenshiftOpenshiftcluster type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureRedhatopenshiftOpenshiftcluster` Composition type (`composition.krateo.io/v0-1-0`,
plural `azureredhatopenshiftopenshiftclusters`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-redhatopenshift-openshiftcluster`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureRedhatopenshiftOpenshiftcluster
metadata:
  name: my-openshiftcluster
  namespace: azure-redhatopenshift-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... OpenShiftCluster spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azureredhatopenshiftopenshiftclusters.composition.krateo.io -n azure-redhatopenshift-system
kubectl get openshiftclusters.redhatopenshift.azure.com -A
```
