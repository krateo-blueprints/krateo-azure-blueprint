# Krateo Blueprint — Azure Machinelearningservices WorkspacesConnection

> Generated by `tools/asogen` from the Azure Service Operator `WorkspacesConnection` CRD (`machinelearningservices.azure.com`).

Provisions an Azure Machinelearningservices **WorkspacesConnection** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `machinelearningservices.azure.com/v1api20240401` `WorkspacesConnection` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureMachinelearningservicesWorkspacesconnection` Composition you create
becomes an Azure WorkspacesConnection.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20240401`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO WorkspacesConnection spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-machinelearningservices-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureMachinelearningservicesWorkspacesconnection type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureMachinelearningservicesWorkspacesconnection` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuremachinelearningservicesworkspacesconnections`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-machinelearningservices-workspacesconnection`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureMachinelearningservicesWorkspacesconnection
metadata:
  name: my-workspacesconnection
  namespace: azure-machinelearningservices-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... WorkspacesConnection spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuremachinelearningservicesworkspacesconnections.composition.krateo.io -n azure-machinelearningservices-system
kubectl get workspacesconnections.machinelearningservices.azure.com -A
```
