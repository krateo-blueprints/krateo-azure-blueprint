# Krateo Blueprint — Azure Compute Disk

> Generated by `tools/asogen` from the Azure Service Operator `Disk` CRD (`compute.azure.com`).

Provisions an Azure Compute **Disk** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `compute.azure.com/v1api20240302` `Disk` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureComputeDisk` Composition you create
becomes an Azure Disk.

This CRD serves **8** versions upstream; this blueprint targets
`v1api20240302`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Disk spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-compute-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureComputeDisk type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureComputeDisk` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurecomputedisks`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-compute-disk`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureComputeDisk
metadata:
  name: my-disk
  namespace: azure-compute-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Disk spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurecomputedisks.composition.krateo.io -n azure-compute-system
kubectl get disks.compute.azure.com -A
```
