# Krateo Blueprint — Azure Kusto ClusterPrincipalAssignment

> Generated by `tools/asogen` from the Azure Service Operator `ClusterPrincipalAssignment` CRD (`kusto.azure.com`).

Provisions an Azure Kusto **ClusterPrincipalAssignment** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `kusto.azure.com/v20240413` `ClusterPrincipalAssignment` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureKustoClusterprincipalassignment` Composition you create
becomes an Azure ClusterPrincipalAssignment.

This CRD serves **2** versions upstream; this blueprint targets
`v20240413`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO ClusterPrincipalAssignment spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-kusto-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureKustoClusterprincipalassignment type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureKustoClusterprincipalassignment` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurekustoclusterprincipalassignments`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-kusto-clusterprincipalassignment`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureKustoClusterprincipalassignment
metadata:
  name: my-clusterprincipalassignment
  namespace: azure-kusto-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... ClusterPrincipalAssignment spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurekustoclusterprincipalassignments.composition.krateo.io -n azure-kusto-system
kubectl get clusterprincipalassignments.kusto.azure.com -A
```
