# Krateo Blueprint — Azure Appconfiguration ConfigurationStore

> Generated by `tools/asogen` from the Azure Service Operator `ConfigurationStore` CRD (`appconfiguration.azure.com`).

Provisions an Azure Appconfiguration **ConfigurationStore** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `appconfiguration.azure.com/v1api20220501` `ConfigurationStore` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureAppconfigurationConfigurationstore` Composition you create
becomes an Azure ConfigurationStore.

This CRD serves **6** versions upstream; this blueprint targets
`v1api20220501`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO ConfigurationStore spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-appconfiguration-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureAppconfigurationConfigurationstore type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureAppconfigurationConfigurationstore` Composition type (`composition.krateo.io/v0-1-0`,
plural `azureappconfigurationconfigurationstores`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-appconfiguration-configurationstore`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureAppconfigurationConfigurationstore
metadata:
  name: my-configurationstore
  namespace: azure-appconfiguration-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... ConfigurationStore spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azureappconfigurationconfigurationstores.composition.krateo.io -n azure-appconfiguration-system
kubectl get configurationstores.appconfiguration.azure.com -A
```
