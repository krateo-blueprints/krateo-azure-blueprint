# Krateo Blueprint — Azure Notificationhubs Namespace

> Generated by `tools/asogen` from the Azure Service Operator `Namespace` CRD (`notificationhubs.azure.com`).

Provisions an Azure Notificationhubs **Namespace** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `notificationhubs.azure.com/v1api20230901` `Namespace` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureNotificationhubsNamespace` Composition you create
becomes an Azure Namespace.

This CRD serves **2** versions upstream; this blueprint targets
`v1api20230901`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Namespace spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-notificationhubs-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureNotificationhubsNamespace type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureNotificationhubsNamespace` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurenotificationhubsnamespaces`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-notificationhubs-namespace`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureNotificationhubsNamespace
metadata:
  name: my-namespace
  namespace: azure-notificationhubs-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Namespace spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurenotificationhubsnamespaces.composition.krateo.io -n azure-notificationhubs-system
kubectl get namespaces.notificationhubs.azure.com -A
```
