# Krateo Blueprint — Azure Dbformysql User

> Generated by `tools/asogen` from the Azure Service Operator `User` CRD (`dbformysql.azure.com`).

Provisions an Azure Dbformysql **User** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `dbformysql.azure.com/v1` `User` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureDbformysqlUser` Composition you create
becomes an Azure User.

This CRD serves **1** versions upstream; this blueprint targets
`v1`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO User spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-dbformysql-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureDbformysqlUser type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureDbformysqlUser` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuredbformysqlusers`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-dbformysql-user`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureDbformysqlUser
metadata:
  name: my-user
  namespace: azure-dbformysql-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... User spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuredbformysqlusers.composition.krateo.io -n azure-dbformysql-system
kubectl get users.dbformysql.azure.com -A
```
