# Krateo Blueprint — Azure Documentdb MongodbDatabaseCollection

> Generated by `tools/asogen` from the Azure Service Operator `MongodbDatabaseCollection` CRD (`documentdb.azure.com`).

Provisions an Azure Documentdb **MongodbDatabaseCollection** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `documentdb.azure.com/v1api20240815` `MongodbDatabaseCollection` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureDocumentdbMongodbdatabasecollection` Composition you create
becomes an Azure MongodbDatabaseCollection.

This CRD serves **6** versions upstream; this blueprint targets
`v1api20240815`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO MongodbDatabaseCollection spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-documentdb-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureDocumentdbMongodbdatabasecollection type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureDocumentdbMongodbdatabasecollection` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuredocumentdbmongodbdatabasecollections`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-documentdb-mongodbdatabasecollection`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureDocumentdbMongodbdatabasecollection
metadata:
  name: my-mongodbdatabasecollection
  namespace: azure-documentdb-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... MongodbDatabaseCollection spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuredocumentdbmongodbdatabasecollections.composition.krateo.io -n azure-documentdb-system
kubectl get mongodbdatabasecollections.documentdb.azure.com -A
```
