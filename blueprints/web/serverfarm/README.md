# Krateo Blueprint — Azure Web ServerFarm

> Generated by `tools/asogen` from the Azure Service Operator `ServerFarm` CRD (`web.azure.com`).

Provisions an Azure Web **ServerFarm** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `web.azure.com/v1api20220301` `ServerFarm` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureWebServerfarm` Composition you create
becomes an Azure ServerFarm.

This CRD serves **6** versions upstream; this blueprint targets
`v1api20220301`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO ServerFarm spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-web-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureWebServerfarm type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureWebServerfarm` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurewebserverfarms`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-web-serverfarm`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureWebServerfarm
metadata:
  name: my-serverfarm
  namespace: azure-web-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... ServerFarm spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurewebserverfarms.composition.krateo.io -n azure-web-system
kubectl get serverfarms.web.azure.com -A
```
