# Krateo Blueprint — Azure Appconfiguration Replica

> Generated by `tools/asogen` from the Azure Service Operator `Replica` CRD (`appconfiguration.azure.com`).

Provisions an Azure Appconfiguration **Replica** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `appconfiguration.azure.com/v20240601` `Replica` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureAppconfigurationReplica` Composition you create
becomes an Azure Replica.

This CRD serves **2** versions upstream; this blueprint targets
`v20240601`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Replica spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-appconfiguration-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureAppconfigurationReplica type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureAppconfigurationReplica` Composition type (`composition.krateo.io/v0-1-0`,
plural `azureappconfigurationreplicas`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-appconfiguration-replica`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureAppconfigurationReplica
metadata:
  name: my-replica
  namespace: azure-appconfiguration-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Replica spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azureappconfigurationreplicas.composition.krateo.io -n azure-appconfiguration-system
kubectl get replicas.appconfiguration.azure.com -A
```
