# Krateo Blueprint — Azure Alertsmanagement SmartDetectorAlertRule

> Generated by `tools/asogen` from the Azure Service Operator `SmartDetectorAlertRule` CRD (`alertsmanagement.azure.com`).

Provisions an Azure Alertsmanagement **SmartDetectorAlertRule** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `alertsmanagement.azure.com/v1api20210401` `SmartDetectorAlertRule` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureAlertsmanagementSmartdetectoralertrule` Composition you create
becomes an Azure SmartDetectorAlertRule.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20210401`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO SmartDetectorAlertRule spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-alertsmanagement-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureAlertsmanagementSmartdetectoralertrule type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureAlertsmanagementSmartdetectoralertrule` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurealertsmanagementsmartdetectoralertrules`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-alertsmanagement-smartdetectoralertrule`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureAlertsmanagementSmartdetectoralertrule
metadata:
  name: my-smartdetectoralertrule
  namespace: azure-alertsmanagement-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... SmartDetectorAlertRule spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurealertsmanagementsmartdetectoralertrules.composition.krateo.io -n azure-alertsmanagement-system
kubectl get smartdetectoralertrules.alertsmanagement.azure.com -A
```
