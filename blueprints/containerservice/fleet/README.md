# Krateo Blueprint — Azure Containerservice Fleet

> Generated by `tools/asogen` from the Azure Service Operator `Fleet` CRD (`containerservice.azure.com`).

Provisions an Azure Containerservice **Fleet** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `containerservice.azure.com/v1api20250301` `Fleet` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureContainerserviceFleet` Composition you create
becomes an Azure Fleet.

This CRD serves **2** versions upstream; this blueprint targets
`v1api20250301`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Fleet spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-containerservice-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureContainerserviceFleet type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureContainerserviceFleet` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurecontainerservicefleets`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-containerservice-fleet`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureContainerserviceFleet
metadata:
  name: my-fleet
  namespace: azure-containerservice-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Fleet spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurecontainerservicefleets.composition.krateo.io -n azure-containerservice-system
kubectl get fleets.containerservice.azure.com -A
```
