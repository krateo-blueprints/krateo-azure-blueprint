# Krateo Blueprint — Azure Dataprotection BackupVault

> Generated by `tools/asogen` from the Azure Service Operator `BackupVault` CRD (`dataprotection.azure.com`).

Provisions an Azure Dataprotection **BackupVault** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `dataprotection.azure.com/v1api20231101` `BackupVault` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureDataprotectionBackupvault` Composition you create
becomes an Azure BackupVault.

This CRD serves **8** versions upstream; this blueprint targets
`v1api20231101`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO BackupVault spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-dataprotection-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureDataprotectionBackupvault type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureDataprotectionBackupvault` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuredataprotectionbackupvaults`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-dataprotection-backupvault`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureDataprotectionBackupvault
metadata:
  name: my-backupvault
  namespace: azure-dataprotection-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... BackupVault spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuredataprotectionbackupvaults.composition.krateo.io -n azure-dataprotection-system
kubectl get backupvaults.dataprotection.azure.com -A
```
