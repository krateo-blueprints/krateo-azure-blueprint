# Krateo Blueprint — Azure Compute CapacityReservationGroup

> Generated by `tools/asogen` from the Azure Service Operator `CapacityReservationGroup` CRD (`compute.azure.com`).

Provisions an Azure Compute **CapacityReservationGroup** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `compute.azure.com/v1api20250401` `CapacityReservationGroup` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureComputeCapacityreservationgroup` Composition you create
becomes an Azure CapacityReservationGroup.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20250401`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO CapacityReservationGroup spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-compute-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureComputeCapacityreservationgroup type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureComputeCapacityreservationgroup` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurecomputecapacityreservationgroups`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-compute-capacityreservationgroup`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureComputeCapacityreservationgroup
metadata:
  name: my-capacityreservationgroup
  namespace: azure-compute-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... CapacityReservationGroup spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurecomputecapacityreservationgroups.composition.krateo.io -n azure-compute-system
kubectl get capacityreservationgroups.compute.azure.com -A
```
