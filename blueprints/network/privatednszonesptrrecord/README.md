# Krateo Blueprint — Azure Network PrivateDnsZonesPTRRecord

> Generated by `tools/asogen` from the Azure Service Operator `PrivateDnsZonesPTRRecord` CRD (`network.azure.com`).

Provisions an Azure Network **PrivateDnsZonesPTRRecord** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `network.azure.com/v1api20240601` `PrivateDnsZonesPTRRecord` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureNetworkPrivatednszonesptrrecord` Composition you create
becomes an Azure PrivateDnsZonesPTRRecord.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20240601`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO PrivateDnsZonesPTRRecord spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-network-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureNetworkPrivatednszonesptrrecord type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureNetworkPrivatednszonesptrrecord` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurenetworkprivatednszonesptrrecords`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-network-privatednszonesptrrecord`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureNetworkPrivatednszonesptrrecord
metadata:
  name: my-privatednszonesptrrecord
  namespace: azure-network-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... PrivateDnsZonesPTRRecord spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurenetworkprivatednszonesptrrecords.composition.krateo.io -n azure-network-system
kubectl get privatednszonesptrrecords.network.azure.com -A
```
