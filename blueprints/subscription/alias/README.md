# Krateo Blueprint — Azure Subscription Alias

> Generated by `tools/asogen` from the Azure Service Operator `Alias` CRD (`subscription.azure.com`).

Provisions an Azure Subscription **Alias** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `subscription.azure.com/v1api20211001` `Alias` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureSubscriptionAlias` Composition you create
becomes an Azure Alias.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20211001`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Alias spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-subscription-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureSubscriptionAlias type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureSubscriptionAlias` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuresubscriptionaliases`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-subscription-alias`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureSubscriptionAlias
metadata:
  name: my-alias
  namespace: azure-subscription-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Alias spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuresubscriptionaliases.composition.krateo.io -n azure-subscription-system
kubectl get aliass.subscription.azure.com -A
```
