# Krateo Blueprint — Azure Containerservice MaintenanceConfiguration

> Generated by `tools/asogen` from the Azure Service Operator `MaintenanceConfiguration` CRD (`containerservice.azure.com`).

Provisions an Azure Containerservice **MaintenanceConfiguration** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `containerservice.azure.com/v1api20250801` `MaintenanceConfiguration` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureContainerserviceMaintenanceconfiguration` Composition you create
becomes an Azure MaintenanceConfiguration.

This CRD serves **6** versions upstream; this blueprint targets
`v1api20250801`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO MaintenanceConfiguration spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-containerservice-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureContainerserviceMaintenanceconfiguration type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureContainerserviceMaintenanceconfiguration` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurecontainerservicemaintenanceconfigurations`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-containerservice-maintenanceconfiguration`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureContainerserviceMaintenanceconfiguration
metadata:
  name: my-maintenanceconfiguration
  namespace: azure-containerservice-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... MaintenanceConfiguration spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurecontainerservicemaintenanceconfigurations.composition.krateo.io -n azure-containerservice-system
kubectl get maintenanceconfigurations.containerservice.azure.com -A
```
