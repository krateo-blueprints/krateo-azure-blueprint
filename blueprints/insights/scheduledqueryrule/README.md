# Krateo Blueprint — Azure Insights ScheduledQueryRule

> Generated by `tools/asogen` from the Azure Service Operator `ScheduledQueryRule` CRD (`insights.azure.com`).

Provisions an Azure Insights **ScheduledQueryRule** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `insights.azure.com/v1api20220615` `ScheduledQueryRule` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureInsightsScheduledqueryrule` Composition you create
becomes an Azure ScheduledQueryRule.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20220615`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO ScheduledQueryRule spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-insights-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureInsightsScheduledqueryrule type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureInsightsScheduledqueryrule` Composition type (`composition.krateo.io/v0-1-0`,
plural `azureinsightsscheduledqueryrules`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-insights-scheduledqueryrule`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureInsightsScheduledqueryrule
metadata:
  name: my-scheduledqueryrule
  namespace: azure-insights-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... ScheduledQueryRule spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azureinsightsscheduledqueryrules.composition.krateo.io -n azure-insights-system
kubectl get scheduledqueryrules.insights.azure.com -A
```
