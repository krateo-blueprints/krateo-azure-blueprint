# Krateo Blueprint — Azure Sql ServersKey

> Generated by `tools/asogen` from the Azure Service Operator `ServersKey` CRD (`sql.azure.com`).

Provisions an Azure Sql **ServersKey** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `sql.azure.com/v20250101` `ServersKey` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureSQLServerskey` Composition you create
becomes an Azure ServersKey.

This CRD serves **4** versions upstream; this blueprint targets
`v20250101`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO ServersKey spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-sql-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureSQLServerskey type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureSQLServerskey` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuresqlserverskeys`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-sql-serverskey`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureSQLServerskey
metadata:
  name: my-serverskey
  namespace: azure-sql-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... ServersKey spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuresqlserverskeys.composition.krateo.io -n azure-sql-system
kubectl get serverskeys.sql.azure.com -A
```
