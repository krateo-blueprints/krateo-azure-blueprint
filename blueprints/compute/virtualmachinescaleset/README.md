# Krateo Blueprint — Azure Compute VirtualMachineScaleSet

> Generated by `tools/asogen` from the Azure Service Operator `VirtualMachineScaleSet` CRD (`compute.azure.com`).

Provisions an Azure Compute **VirtualMachineScaleSet** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `compute.azure.com/v1api20220301` `VirtualMachineScaleSet` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureComputeVirtualmachinescaleset` Composition you create
becomes an Azure VirtualMachineScaleSet.

This CRD serves **8** versions upstream; this blueprint targets
`v1api20220301`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO VirtualMachineScaleSet spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-compute-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureComputeVirtualmachinescaleset type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureComputeVirtualmachinescaleset` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurecomputevirtualmachinescalesets`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-compute-virtualmachinescaleset`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureComputeVirtualmachinescaleset
metadata:
  name: my-virtualmachinescaleset
  namespace: azure-compute-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... VirtualMachineScaleSet spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurecomputevirtualmachinescalesets.composition.krateo.io -n azure-compute-system
kubectl get virtualmachinescalesets.compute.azure.com -A
```
