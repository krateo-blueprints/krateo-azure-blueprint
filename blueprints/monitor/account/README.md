# Krateo Blueprint — Azure Monitor Account

> Generated by `tools/asogen` from the Azure Service Operator `Account` CRD (`monitor.azure.com`).

Provisions an Azure Monitor **Account** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `monitor.azure.com/v1api20230403` `Account` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureMonitorAccount` Composition you create
becomes an Azure Account.

This CRD serves **2** versions upstream; this blueprint targets
`v1api20230403`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Account spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-monitor-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureMonitorAccount type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureMonitorAccount` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuremonitoraccounts`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-monitor-account`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureMonitorAccount
metadata:
  name: my-account
  namespace: azure-monitor-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Account spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuremonitoraccounts.composition.krateo.io -n azure-monitor-system
kubectl get accounts.monitor.azure.com -A
```
