# Krateo Blueprint — Azure Web SitesSourcecontrol

> Generated by `tools/asogen` from the Azure Service Operator `SitesSourcecontrol` CRD (`web.azure.com`).

Provisions an Azure Web **SitesSourcecontrol** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `web.azure.com/v1api20220301` `SitesSourcecontrol` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureWebSitessourcecontrol` Composition you create
becomes an Azure SitesSourcecontrol.

This CRD serves **6** versions upstream; this blueprint targets
`v1api20220301`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO SitesSourcecontrol spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-azure-blueprint/releases
kubectl create namespace azure-web-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-azure-blueprint/releases/download/${VERSION}/compositiondefinition-azure-web-sitessourcecontrol.yaml"   # publishes the AzureWebSitessourcecontrol type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureWebSitessourcecontrol` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `azurewebsitessourcecontrols`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-web-sitessourcecontrol` at that version.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/vX-Y-Z   # VERSION with dashes, e.g. v0-1-6
kind: AzureWebSitessourcecontrol
metadata:
  name: my-sitessourcecontrol
  namespace: azure-web-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... SitesSourcecontrol spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurewebsitessourcecontrols.composition.krateo.io -n azure-web-system
kubectl get sitessourcecontrols.web.azure.com -A
```
