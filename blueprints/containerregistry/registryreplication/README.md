# Krateo Blueprint — Azure Containerregistry RegistryReplication

> Generated by `tools/asogen` from the Azure Service Operator `RegistryReplication` CRD (`containerregistry.azure.com`).

Provisions an Azure Containerregistry **RegistryReplication** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `containerregistry.azure.com/v1api20230701` `RegistryReplication` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureContainerregistryRegistryreplication` Composition you create
becomes an Azure RegistryReplication.

This CRD serves **2** versions upstream; this blueprint targets
`v1api20230701`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO RegistryReplication spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-azure-blueprint/releases
kubectl create namespace azure-containerregistry-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-azure-blueprint/releases/download/${VERSION}/compositiondefinition-azure-containerregistry-registryreplication.yaml"   # publishes the AzureContainerregistryRegistryreplication type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureContainerregistryRegistryreplication` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `azurecontainerregistryregistryreplications`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-containerregistry-registryreplication` at that version.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/vX-Y-Z   # VERSION with dashes, e.g. v0-1-6
kind: AzureContainerregistryRegistryreplication
metadata:
  name: my-registryreplication
  namespace: azure-containerregistry-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... RegistryReplication spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurecontainerregistryregistryreplications.composition.krateo.io -n azure-containerregistry-system
kubectl get registryreplications.containerregistry.azure.com -A
```
