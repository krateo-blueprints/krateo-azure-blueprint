# Krateo Blueprint — Azure Eventgrid EventSubscription

> Generated by `tools/asogen` from the Azure Service Operator `EventSubscription` CRD (`eventgrid.azure.com`).

Provisions an Azure Eventgrid **EventSubscription** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `eventgrid.azure.com/v1api20200601` `EventSubscription` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureEventgridEventsubscription` Composition you create
becomes an Azure EventSubscription.

This CRD serves **6** versions upstream; this blueprint targets
`v1api20200601`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO EventSubscription spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-eventgrid-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureEventgridEventsubscription type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureEventgridEventsubscription` Composition type (`composition.krateo.io/v0-1-0`,
plural `azureeventgrideventsubscriptions`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-eventgrid-eventsubscription`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureEventgridEventsubscription
metadata:
  name: my-eventsubscription
  namespace: azure-eventgrid-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... EventSubscription spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azureeventgrideventsubscriptions.composition.krateo.io -n azure-eventgrid-system
kubectl get eventsubscriptions.eventgrid.azure.com -A
```
