# Krateo Blueprint — Azure Cdn SecurityPolicy

> Generated by `tools/asogen` from the Azure Service Operator `SecurityPolicy` CRD (`cdn.azure.com`).

Provisions an Azure Cdn **SecurityPolicy** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `cdn.azure.com/v1api20230501` `SecurityPolicy` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureCdnSecuritypolicy` Composition you create
becomes an Azure SecurityPolicy.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20230501`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO SecurityPolicy spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-cdn-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureCdnSecuritypolicy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureCdnSecuritypolicy` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurecdnsecuritypolicies`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-cdn-securitypolicy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureCdnSecuritypolicy
metadata:
  name: my-securitypolicy
  namespace: azure-cdn-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... SecurityPolicy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurecdnsecuritypolicies.composition.krateo.io -n azure-cdn-system
kubectl get securitypolicys.cdn.azure.com -A
```
