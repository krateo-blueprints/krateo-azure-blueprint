# Krateo Blueprint — Azure Storage StorageAccountsTableService

> Generated by `tools/asogen` from the Azure Service Operator `StorageAccountsTableService` CRD (`storage.azure.com`).

Provisions an Azure Storage **StorageAccountsTableService** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `storage.azure.com/v1api20230101` `StorageAccountsTableService` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureStorageAccountstableservice` Composition you create
becomes an Azure StorageAccountsTableService.

This CRD serves **10** versions upstream; this blueprint targets
`v1api20230101`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO StorageAccountsTableService spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-storage-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureStorageAccountstableservice type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureStorageAccountstableservice` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurestorageaccountstableservices`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-storage-accountstableservice`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureStorageAccountstableservice
metadata:
  name: my-accountstableservice
  namespace: azure-storage-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... StorageAccountsTableService spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurestorageaccountstableservices.composition.krateo.io -n azure-storage-system
kubectl get storageaccountstableservices.storage.azure.com -A
```
