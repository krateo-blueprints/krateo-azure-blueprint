# Krateo Blueprint — Azure Network PrivateDnsZonesCNAMERecord

> Generated by `tools/asogen` from the Azure Service Operator `PrivateDnsZonesCNAMERecord` CRD (`network.azure.com`).

Provisions an Azure Network **PrivateDnsZonesCNAMERecord** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `network.azure.com/v1api20240601` `PrivateDnsZonesCNAMERecord` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureNetworkPrivatednszonescnamerecord` Composition you create
becomes an Azure PrivateDnsZonesCNAMERecord.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20240601`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO PrivateDnsZonesCNAMERecord spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-network-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureNetworkPrivatednszonescnamerecord type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureNetworkPrivatednszonescnamerecord` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurenetworkprivatednszonescnamerecords`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-network-privatednszonescnamerecord`.
