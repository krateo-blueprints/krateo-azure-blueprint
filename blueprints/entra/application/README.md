# Krateo Blueprint — Azure Entra Application

> Generated by `tools/asogen` from the Azure Service Operator `Application` CRD (`entra.azure.com`).

Provisions an Azure Entra **Application** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `entra.azure.com/v1` `Application` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureEntraApplication` Composition you create
becomes an Azure Application.

This CRD serves **1** versions upstream; this blueprint targets
`v1`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Application spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-entra-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureEntraApplication type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureEntraApplication` Composition type (`composition.krateo.io/v0-1-0`,
plural `azureentraapplications`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-entra-application`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureEntraApplication
metadata:
  name: my-application
  namespace: azure-entra-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Application spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azureentraapplications.composition.krateo.io -n azure-entra-system
kubectl get applications.entra.azure.com -A
```
