# Krateo Blueprint — Azure Network PrivateLinkService

> Generated by `tools/asogen` from the Azure Service Operator `PrivateLinkService` CRD (`network.azure.com`).

Provisions an Azure Network **PrivateLinkService** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `network.azure.com/v1api20240301` `PrivateLinkService` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureNetworkPrivatelinkservice` Composition you create
becomes an Azure PrivateLinkService.

This CRD serves **6** versions upstream; this blueprint targets
`v1api20240301`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO PrivateLinkService spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-network-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureNetworkPrivatelinkservice type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureNetworkPrivatelinkservice` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurenetworkprivatelinkservices`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-network-privatelinkservice`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureNetworkPrivatelinkservice
metadata:
  name: my-privatelinkservice
  namespace: azure-network-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... PrivateLinkService spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurenetworkprivatelinkservices.composition.krateo.io -n azure-network-system
kubectl get privatelinkservices.network.azure.com -A
```
