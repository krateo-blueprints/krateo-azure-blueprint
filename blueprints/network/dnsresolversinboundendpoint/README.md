# Krateo Blueprint — Azure Network DnsResolversInboundEndpoint

> Generated by `tools/asogen` from the Azure Service Operator `DnsResolversInboundEndpoint` CRD (`network.azure.com`).

Provisions an Azure Network **DnsResolversInboundEndpoint** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `network.azure.com/v1api20220701` `DnsResolversInboundEndpoint` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureNetworkDnsresolversinboundendpoint` Composition you create
becomes an Azure DnsResolversInboundEndpoint.

This CRD serves **2** versions upstream; this blueprint targets
`v1api20220701`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO DnsResolversInboundEndpoint spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-network-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureNetworkDnsresolversinboundendpoint type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureNetworkDnsresolversinboundendpoint` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurenetworkdnsresolversinboundendpoints`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-network-dnsresolversinboundendpoint`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureNetworkDnsresolversinboundendpoint
metadata:
  name: my-dnsresolversinboundendpoint
  namespace: azure-network-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... DnsResolversInboundEndpoint spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurenetworkdnsresolversinboundendpoints.composition.krateo.io -n azure-network-system
kubectl get dnsresolversinboundendpoints.network.azure.com -A
```
