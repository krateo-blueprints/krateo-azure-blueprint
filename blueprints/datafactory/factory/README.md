# Krateo Blueprint — Azure Datafactory Factory

> Generated by `tools/asogen` from the Azure Service Operator `Factory` CRD (`datafactory.azure.com`).

Provisions an Azure Datafactory **Factory** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `datafactory.azure.com/v1api20180601` `Factory` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureDatafactoryFactory` Composition you create
becomes an Azure Factory.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20180601`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Factory spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-datafactory-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureDatafactoryFactory type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureDatafactoryFactory` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuredatafactoryfactories`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-datafactory-factory`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureDatafactoryFactory
metadata:
  name: my-factory
  namespace: azure-datafactory-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Factory spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuredatafactoryfactories.composition.krateo.io -n azure-datafactory-system
kubectl get factorys.datafactory.azure.com -A
```
