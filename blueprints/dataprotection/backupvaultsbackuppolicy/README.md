# Krateo Blueprint — Azure Dataprotection BackupVaultsBackupPolicy

> Generated by `tools/asogen` from the Azure Service Operator `BackupVaultsBackupPolicy` CRD (`dataprotection.azure.com`).

Provisions an Azure Dataprotection **BackupVaultsBackupPolicy** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `dataprotection.azure.com/v1api20231101` `BackupVaultsBackupPolicy` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureDataprotectionBackupvaultsbackuppolicy` Composition you create
becomes an Azure BackupVaultsBackupPolicy.

This CRD serves **8** versions upstream; this blueprint targets
`v1api20231101`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO BackupVaultsBackupPolicy spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-dataprotection-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureDataprotectionBackupvaultsbackuppolicy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureDataprotectionBackupvaultsbackuppolicy` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuredataprotectionbackupvaultsbackuppolicies`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-dataprotection-backupvaultsbackuppolicy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureDataprotectionBackupvaultsbackuppolicy
metadata:
  name: my-backupvaultsbackuppolicy
  namespace: azure-dataprotection-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... BackupVaultsBackupPolicy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuredataprotectionbackupvaultsbackuppolicies.composition.krateo.io -n azure-dataprotection-system

```
