# Krateo Blueprint — Azure Storage StorageAccountsQueueServicesQueue

> Generated by `tools/asogen` from the Azure Service Operator `StorageAccountsQueueServicesQueue` CRD (`storage.azure.com`).

Provisions an Azure Storage **StorageAccountsQueueServicesQueue** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `storage.azure.com/v1api20230101` `StorageAccountsQueueServicesQueue` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureStorageAccountsqueueservicesqueue` Composition you create
becomes an Azure StorageAccountsQueueServicesQueue.

This CRD serves **14** versions upstream; this blueprint targets
`v1api20230101`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO StorageAccountsQueueServicesQueue spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-storage-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureStorageAccountsqueueservicesqueue type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureStorageAccountsqueueservicesqueue` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurestorageaccountsqueueservicesqueues`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-storage-accountsqueueservicesqueue`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureStorageAccountsqueueservicesqueue
metadata:
  name: my-accountsqueueservicesqueue
  namespace: azure-storage-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... StorageAccountsQueueServicesQueue spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurestorageaccountsqueueservicesqueues.composition.krateo.io -n azure-storage-system
kubectl get storageaccountsqueueservicesqueues.storage.azure.com -A
```
