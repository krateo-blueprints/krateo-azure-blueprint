# Krateo Blueprint — Azure Apimanagement Policy

> Generated by `tools/asogen` from the Azure Service Operator `Policy` CRD (`apimanagement.azure.com`).

Provisions an Azure Apimanagement **Policy** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `apimanagement.azure.com/v1api20240501` `Policy` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureApimanagementPolicy` Composition you create
becomes an Azure Policy.

This CRD serves **12** versions upstream; this blueprint targets
`v1api20240501`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Policy spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-apimanagement-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureApimanagementPolicy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureApimanagementPolicy` Composition type (`composition.krateo.io/v0-1-0`,
plural `azureapimanagementpolicies`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-apimanagement-policy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureApimanagementPolicy
metadata:
  name: my-policy
  namespace: azure-apimanagement-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Policy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azureapimanagementpolicies.composition.krateo.io -n azure-apimanagement-system
kubectl get policys.apimanagement.azure.com -A
```
