# Krateo Blueprint — Azure Devices IotHub

> Generated by `tools/asogen` from the Azure Service Operator `IotHub` CRD (`devices.azure.com`).

Provisions an Azure Devices **IotHub** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `devices.azure.com/v1api20210702` `IotHub` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureDevicesIothub` Composition you create
becomes an Azure IotHub.

This CRD serves **2** versions upstream; this blueprint targets
`v1api20210702`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO IotHub spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-devices-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureDevicesIothub type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureDevicesIothub` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuredevicesiothubs`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-devices-iothub`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureDevicesIothub
metadata:
  name: my-iothub
  namespace: azure-devices-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... IotHub spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuredevicesiothubs.composition.krateo.io -n azure-devices-system
kubectl get iothubs.devices.azure.com -A
```
