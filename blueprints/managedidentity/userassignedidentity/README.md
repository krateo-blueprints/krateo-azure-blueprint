# Krateo Blueprint — Azure Managedidentity UserAssignedIdentity

> Generated by `tools/asogen` from the Azure Service Operator `UserAssignedIdentity` CRD (`managedidentity.azure.com`).

Provisions an Azure Managedidentity **UserAssignedIdentity** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `managedidentity.azure.com/v1api20230131` `UserAssignedIdentity` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureManagedidentityUserassignedidentity` Composition you create
becomes an Azure UserAssignedIdentity.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20230131`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO UserAssignedIdentity spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-managedidentity-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureManagedidentityUserassignedidentity type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureManagedidentityUserassignedidentity` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuremanagedidentityuserassignedidentities`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-managedidentity-userassignedidentity`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureManagedidentityUserassignedidentity
metadata:
  name: my-userassignedidentity
  namespace: azure-managedidentity-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... UserAssignedIdentity spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuremanagedidentityuserassignedidentities.composition.krateo.io -n azure-managedidentity-system
kubectl get userassignedidentitys.managedidentity.azure.com -A
```
