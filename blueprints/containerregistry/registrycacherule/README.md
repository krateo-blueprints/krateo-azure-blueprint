# Krateo Blueprint — Azure Containerregistry RegistryCacheRule

> Generated by `tools/asogen` from the Azure Service Operator `RegistryCacheRule` CRD (`containerregistry.azure.com`).

Provisions an Azure Containerregistry **RegistryCacheRule** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `containerregistry.azure.com/v20251101` `RegistryCacheRule` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureContainerregistryRegistrycacherule` Composition you create
becomes an Azure RegistryCacheRule.

This CRD serves **2** versions upstream; this blueprint targets
`v20251101`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO RegistryCacheRule spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-containerregistry-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureContainerregistryRegistrycacherule type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureContainerregistryRegistrycacherule` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurecontainerregistryregistrycacherules`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-containerregistry-registrycacherule`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureContainerregistryRegistrycacherule
metadata:
  name: my-registrycacherule
  namespace: azure-containerregistry-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... RegistryCacheRule spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurecontainerregistryregistrycacherules.composition.krateo.io -n azure-containerregistry-system
kubectl get registrycacherules.containerregistry.azure.com -A
```
