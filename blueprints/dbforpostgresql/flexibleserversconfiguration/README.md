# Krateo Blueprint — Azure Dbforpostgresql FlexibleServersConfiguration

> Generated by `tools/asogen` from the Azure Service Operator `FlexibleServersConfiguration` CRD (`dbforpostgresql.azure.com`).

Provisions an Azure Dbforpostgresql **FlexibleServersConfiguration** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `dbforpostgresql.azure.com/v1api20240801` `FlexibleServersConfiguration` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureDbforpostgresqlFlexibleserversconfiguration` Composition you create
becomes an Azure FlexibleServersConfiguration.

This CRD serves **12** versions upstream; this blueprint targets
`v1api20240801`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO FlexibleServersConfiguration spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-dbforpostgresql-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureDbforpostgresqlFlexibleserversconfiguration type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureDbforpostgresqlFlexibleserversconfiguration` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuredbforpostgresqlflexibleserversconfigurations`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-dbforpostgresql-flexibleserversconfiguration`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureDbforpostgresqlFlexibleserversconfiguration
metadata:
  name: my-flexibleserversconfiguration
  namespace: azure-dbforpostgresql-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... FlexibleServersConfiguration spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuredbforpostgresqlflexibleserversconfigurations.composition.krateo.io -n azure-dbforpostgresql-system
kubectl get flexibleserversconfigurations.dbforpostgresql.azure.com -A
```
