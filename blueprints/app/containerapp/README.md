# Krateo Blueprint — Azure App ContainerApp

> Generated by `tools/asogen` from the Azure Service Operator `ContainerApp` CRD (`app.azure.com`).

Provisions an Azure App **ContainerApp** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `app.azure.com/v1api20250101` `ContainerApp` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureAppContainerapp` Composition you create
becomes an Azure ContainerApp.

This CRD serves **8** versions upstream; this blueprint targets
`v1api20250101`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO ContainerApp spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-app-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureAppContainerapp type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureAppContainerapp` Composition type (`composition.krateo.io/v0-1-0`,
plural `azureappcontainerapps`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-app-containerapp`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureAppContainerapp
metadata:
  name: my-containerapp
  namespace: azure-app-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... ContainerApp spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azureappcontainerapps.composition.krateo.io -n azure-app-system
kubectl get containerapps.app.azure.com -A
```
