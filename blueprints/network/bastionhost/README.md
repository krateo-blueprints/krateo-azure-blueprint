# Krateo Blueprint — Azure Network BastionHost

> Generated by `tools/asogen` from the Azure Service Operator `BastionHost` CRD (`network.azure.com`).

Provisions an Azure Network **BastionHost** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `network.azure.com/v1api20240301` `BastionHost` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureNetworkBastionhost` Composition you create
becomes an Azure BastionHost.

This CRD serves **6** versions upstream; this blueprint targets
`v1api20240301`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO BastionHost spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-network-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureNetworkBastionhost type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureNetworkBastionhost` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurenetworkbastionhosts`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-network-bastionhost`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureNetworkBastionhost
metadata:
  name: my-bastionhost
  namespace: azure-network-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... BastionHost spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurenetworkbastionhosts.composition.krateo.io -n azure-network-system
kubectl get bastionhosts.network.azure.com -A
```
