# Krateo Blueprint — Azure Machinelearningservices Workspace

> Generated by `tools/asogen` from the Azure Service Operator `Workspace` CRD (`machinelearningservices.azure.com`).

Provisions an Azure Machinelearningservices **Workspace** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `machinelearningservices.azure.com/v1api20240401` `Workspace` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureMachinelearningservicesWorkspace` Composition you create
becomes an Azure Workspace.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20240401`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Workspace spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-machinelearningservices-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureMachinelearningservicesWorkspace type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureMachinelearningservicesWorkspace` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuremachinelearningservicesworkspaces`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-machinelearningservices-workspace`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureMachinelearningservicesWorkspace
metadata:
  name: my-workspace
  namespace: azure-machinelearningservices-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Workspace spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuremachinelearningservicesworkspaces.composition.krateo.io -n azure-machinelearningservices-system
kubectl get workspaces.machinelearningservices.azure.com -A
```
