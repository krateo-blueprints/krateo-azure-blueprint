# Krateo Blueprint — Azure Dbformysql FlexibleServer

> Generated by `tools/asogen` from the Azure Service Operator `FlexibleServer` CRD (`dbformysql.azure.com`).

Provisions an Azure Dbformysql **FlexibleServer** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `dbformysql.azure.com/v1api20231230` `FlexibleServer` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureDbformysqlFlexibleserver` Composition you create
becomes an Azure FlexibleServer.

This CRD serves **16** versions upstream; this blueprint targets
`v1api20231230`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO FlexibleServer spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-dbformysql-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureDbformysqlFlexibleserver type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureDbformysqlFlexibleserver` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuredbformysqlflexibleservers`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-dbformysql-flexibleserver`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureDbformysqlFlexibleserver
metadata:
  name: my-flexibleserver
  namespace: azure-dbformysql-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... FlexibleServer spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuredbformysqlflexibleservers.composition.krateo.io -n azure-dbformysql-system
kubectl get flexibleservers.dbformysql.azure.com -A
```
