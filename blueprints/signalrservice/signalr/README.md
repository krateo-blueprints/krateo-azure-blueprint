# Krateo Blueprint — Azure Signalrservice SignalR

> Generated by `tools/asogen` from the Azure Service Operator `SignalR` CRD (`signalrservice.azure.com`).

Provisions an Azure Signalrservice **SignalR** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `signalrservice.azure.com/v1api20240301` `SignalR` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureSignalrserviceSignalr` Composition you create
becomes an Azure SignalR.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20240301`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO SignalR spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-signalrservice-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureSignalrserviceSignalr type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureSignalrserviceSignalr` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuresignalrservicesignalrs`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-signalrservice-signalr`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureSignalrserviceSignalr
metadata:
  name: my-signalr
  namespace: azure-signalrservice-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... SignalR spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuresignalrservicesignalrs.composition.krateo.io -n azure-signalrservice-system
kubectl get signalrs.signalrservice.azure.com -A
```
