# Krateo Blueprint — Azure Dbformariadb Database

> Generated by `tools/asogen` from the Azure Service Operator `Database` CRD (`dbformariadb.azure.com`).

Provisions an Azure Dbformariadb **Database** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `dbformariadb.azure.com/v1api20180601` `Database` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureDbformariadbDatabase` Composition you create
becomes an Azure Database.

This CRD serves **2** versions upstream; this blueprint targets
`v1api20180601`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO Database spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-dbformariadb-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureDbformariadbDatabase type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureDbformariadbDatabase` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuredbformariadbdatabases`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-dbformariadb-database`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureDbformariadbDatabase
metadata:
  name: my-database
  namespace: azure-dbformariadb-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... Database spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuredbformariadbdatabases.composition.krateo.io -n azure-dbformariadb-system
kubectl get databases.dbformariadb.azure.com -A
```
