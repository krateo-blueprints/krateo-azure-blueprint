# Krateo Blueprint — Azure Containerinstance ContainerGroup

> Generated by `tools/asogen` from the Azure Service Operator `ContainerGroup` CRD (`containerinstance.azure.com`).

Provisions an Azure Containerinstance **ContainerGroup** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `containerinstance.azure.com/v1api20211001` `ContainerGroup` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureContainerinstanceContainergroup` Composition you create
becomes an Azure ContainerGroup.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20211001`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO ContainerGroup spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-containerinstance-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureContainerinstanceContainergroup type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureContainerinstanceContainergroup` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurecontainerinstancecontainergroups`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-containerinstance-containergroup`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureContainerinstanceContainergroup
metadata:
  name: my-containergroup
  namespace: azure-containerinstance-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... ContainerGroup spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurecontainerinstancecontainergroups.composition.krateo.io -n azure-containerinstance-system
kubectl get containergroups.containerinstance.azure.com -A
```
