# Krateo Blueprint — Azure Compute AvailabilitySet

> Generated by `tools/asogen` from the Azure Service Operator `AvailabilitySet` CRD (`compute.azure.com`).

Provisions an Azure Compute **AvailabilitySet** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `compute.azure.com/v1api20241101` `AvailabilitySet` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureComputeAvailabilityset` Composition you create
becomes an Azure AvailabilitySet.

This CRD serves **4** versions upstream; this blueprint targets
`v1api20241101`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO AvailabilitySet spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-compute-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureComputeAvailabilityset type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureComputeAvailabilityset` Composition type (`composition.krateo.io/v0-1-0`,
plural `azurecomputeavailabilitysets`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-compute-availabilityset`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureComputeAvailabilityset
metadata:
  name: my-availabilityset
  namespace: azure-compute-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... AvailabilitySet spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azurecomputeavailabilitysets.composition.krateo.io -n azure-compute-system
kubectl get availabilitysets.compute.azure.com -A
```
