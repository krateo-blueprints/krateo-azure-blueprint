# Krateo Blueprint — Azure Documentdb MongodbRoleDefinition

> Generated by `tools/asogen` from the Azure Service Operator `MongodbRoleDefinition` CRD (`documentdb.azure.com`).

Provisions an Azure Documentdb **MongodbRoleDefinition** through
[Azure Service Operator](https://azure.github.io/azure-service-operator/). The chart renders a
native `documentdb.azure.com/v1api20240815` `MongodbRoleDefinition` resource; ASO reconciles it into the real
Azure resource and reports status back.

Once the `CompositionDefinition` is applied, every `AzureDocumentdbMongodbroledefinition` Composition you create
becomes an Azure MongodbRoleDefinition.

This CRD serves **2** versions upstream; this blueprint targets
`v1api20240815`, the newest GA non-storage version.

## Prerequisites

- **Azure Service Operator installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Azure credentials configured** — Workload Identity (recommended) or a service-principal
  Secret. See [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ASO MongodbRoleDefinition spec**, including the required `owner`
reference and `location`. Full schema in [`chart/values.schema.json`](chart/values.schema.json).
The extra `credentialFrom` field sets the `serviceoperator.azure.com/credential-from` annotation;
leave it empty to inherit the credential from the namespace.

## How to install

```sh
kubectl create namespace azure-documentdb-system
kubectl apply -f compositiondefinition.yaml   # publishes the AzureDocumentdbMongodbroledefinition type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AzureDocumentdbMongodbroledefinition` Composition type (`composition.krateo.io/v0-1-0`,
plural `azuredocumentdbmongodbroledefinitions`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/azure-documentdb-mongodbroledefinition`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AzureDocumentdbMongodbroledefinition
metadata:
  name: my-mongodbroledefinition
  namespace: azure-documentdb-system
spec:
  credentialFrom: ""        # optional: a Secret name; empty inherits from the namespace
  owner:
    name: my-resource-group
  # ... MongodbRoleDefinition spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get azuredocumentdbmongodbroledefinitions.composition.krateo.io -n azure-documentdb-system
kubectl get mongodbroledefinitions.documentdb.azure.com -A
```
